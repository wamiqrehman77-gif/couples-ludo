COUPLES LUDO - deploy guide (free)
1. GitHub par naya repo banao aur ye saari files upload karo (server.js, package.json, public/index.html).
2. render.com par free account -> New -> Web Service -> apna repo chuno.
   Build Command: npm install     Start Command: npm start
3. Environment Variables mein ADMIN_PASS daalo (apna secret password).
4. Deploy hone par Render ek link dega (https://....onrender.com). Wohi link
   Pakistan, India, kahin bhi dost/partner ko bhejo. Bas naam likho aur khelo.
Local test: npm install && npm start, phir http://localhost:3000
Note: free plan par server kuch der use na ho to so jata hai, pehla load ~50 sec le sakta hai.
Rooms memory mein rehte hain (server restart par khatam).
